INSTALLATION DE LTSTATION SUR LE POSTE DE LA STATION
====================================================

Ce kit est CONFIDENTIEL (clés de cartes, mots de passe) : le transmettre sur clé USB,
jamais par e-mail ni messagerie.

Poste requis : Windows 10 ou 11, 64 bits, compte administrateur, 4 Go de mémoire au moins.


1. INSTALLER
------------
1. Copier tout le dossier LTStation-Kit sur le poste (par exemple sur le Bureau).
2. Double-cliquer sur INSTALLER.bat, puis répondre « Oui » à la demande d'autorisation de Windows.
3. Attendre le message « Termine » (5 à 15 minutes : PostgreSQL, bases, application).
   Ne pas fermer la fenêtre noire pendant l'installation.
   Windows peut afficher « Windows a protégé votre ordinateur » : « Informations complémentaires »
   puis « Exécuter quand même ».

En cas d'erreur, rien n'est effacé : envoyer le fichier installation.log (dans ce dossier).


2. CONFIGURER LA STATION DANS CENTER
-----------------------------------
1. Lancer l'application avec l'icône LTStation Station du bureau.
2. Ouvrir un navigateur (Chrome, Edge) à l'adresse  http://localhost:8080/
3. Se connecter avec les identifiants Center du fichier ACCES.txt.
4. Créer, dans cet ordre : région et ville, société, station, carburants et prix,
   cuves, pistolets, employés.
5. Activer la station dans l'écran « Activation de station ».


3. PREMIER LANCEMENT DU LOGICIEL STATION
---------------------------------------
L'application ouvre l'assistant de création : renseigner la station, les carburants et prix,
les cuves, les ports série, les pistolets et un employé, puis Enregistrer.
Le poste s'active automatiquement à la fin de l'assistant.


4. BRANCHER LES APPAREILS
------------------------
Avant de brancher : installer les pilotes du fabricant (lecteur de cartes, câbles USB-série).
- Ports série (pompes, jauges, afficheurs) : relever le numéro COM dans le Gestionnaire de
  périphériques de Windows et le saisir dans les réglages des ports du logiciel Station.
- Mode de fonctionnement : IC (cartes) ou Normal (boîtiers), dans les réglages système.
- Cartes : premiers essais sur des cartes de test, jamais sur des cartes de clients.


EN CAS DE PROBLÈME
------------------
Noter : l'écran, l'action faite, le message exact (une photo suffit), l'heure.
Joindre les journaux du jour :  %APPDATA%\LTStation Station\data\logs
(touches Windows + R, coller ce chemin, Entrée), et installation.log s'il existe.
